# Privacy Policy

Briefed is a personal-use tool for a single user. It is not offered as a public
service and is not intended for use by anyone other than its operator.

## Data access

Briefed's Gmail integration reads newsletter messages matching a configured
Gmail query or label, using a Google OAuth refresh token that only the
operator controls. This access is used solely to import those messages into
the operator's own private content archive for personal briefing generation.

## Data storage and sharing

All collected data (Gmail messages, RSS/feed content, Twitter/X posts, and
generated briefings) is stored in the operator's own private database and is
not shared with, sold to, or accessed by any third party.

## Contact

Questions about this policy can be directed to z@zdne.org.
